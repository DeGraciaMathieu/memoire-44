# Plateau & mouvement

## Concepts → implémentation

| Concept                 | Implémentation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Grille                  | 13×9 (`W`, `H`, `src/config.js`), offset **odd-r pointy-top**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Clé d'un hex            | `key(c, r)` → `"c,r"` (`src/hex.js`) — indexe `state.terrain`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Distance                | `hexDistance(a, b)` via coordonnées cube (`toCube`), `src/hex.js`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Voisins                 | `neighbors(c, r)` — deltas différents rangées paires/impaires, filtrés `inBounds`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Secteurs                | `sectorsOf(c, r)` (`src/sectors.js`) : `gauche` / `centre` / `droite`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Hexes à cheval          | Rangées **paires** : colonnes 4 et 8 appartiennent à DEUX secteurs ; rangées impaires : aucun partage                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Terrains                | `TERRAIN` (`src/config.js`) : `label`, `dice.def` (dés retirés), `dice.defArmor` (attaquant blindé), `dice.defArt` (attaquant artillerie — forêt : 0, sans malus), `stops` (arrête le mouvement), `blocksSight` (coupe la ligne de mire — forêt, village et bocage), `elevated` (colline : coupe la ligne de mire seulement entre deux unités en contrebas), `enterAdjacentOnly` / `exitAdjacentOnly` / `noFightOnEnter` (bocage : entrée en premier pas seulement, sortie stoppée à 1 hex, pas de tir le tour d'entrée), `impassable` (rivière : entrée interdite sauf obstacle `makesPassable`, ne bloque jamais la ligne de mire, aucune protection), `noFight` / `noRetreatInto` (mer : 1 hex par tour via `stops` + `exitAdjacentOnly`, aucun tir tant qu'en mer, pas de retraite dans l'eau, vue libre, aucune protection) |
| Obstacles               | `OBSTACLES` (`src/config.js`) + `state.obstacles` + `obstacleAt` (`src/movement.js`) : bunker — accès infanterie seulement, artillerie retranchée fixe, protection non cumulée avec le terrain, ligne de mire coupée, premier drapeau du jet ignoré ; antichar — infanterie seulement (sans restriction de mouvement), aucune protection, vue libre, premier drapeau ignoré ; sacs de sable — aucune restriction d'accès, −1 inf/blindés (rien contre l'artillerie), premier drapeau ignoré, retirés du plateau dès que l'unité quitte l'hex (`removedOnExit` → `dropObstacleOnExit`, événement `obstacleRemoved`) ; pont — `makesPassable` : rend la rivière franchissable, aucune protection (on y combat normalement)                                                                                                         |
| Scénario                | `scenario()` (`src/scenario.js`) : terrain « bocage », 2 bunkers, 2 antichars, 2 sacs de sable + 14 unités (7 par camp)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Cartes personnalisées   | `src/map.js` : format JSON de l'éditeur (`editor.html` / `render/editor.js`), `parseMap` (validation), `setupFromMap` ; jouées via `createGame({ map })` et le bouton « Charger une carte » (`render/app.js`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Occupation              | `unitAt(state, c, r)` (`src/movement.js`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Hexes atteignables      | `reachable(state, unit, maxMove)` : coût 1/hex, hex occupé infranchissable, terrain `stops` arrête net ; bocage : entrée uniquement en premier pas, sortie limitée à l'hex adjacent ; rivière : entrée interdite sans pont (le repli aussi, `resolveCombat`) ; bunker : entrée infanterie seulement, artillerie retranchée fixe                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Capacité de déplacement | `UNITS[type].moveNoFire` (`src/config.js`) — utilisée par la sélection UI (`app.js` `selectUnit`), la validation (`game.js` `moveUnit`) et l'IA (`ai.js` `aiPlanUnit`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Déplacement effectif    | `moveUnit(state, unit, hex)` (`src/game.js`) — **revalide** via `reachable`, renvoie le coût ou `null`, émet `unitMoved`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Layout pixel            | `LAYOUT`, `hexCenter`, `boardSize` (`render/gfx.js`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Picking souris          | `pickHex(x, y)` (`render/gfx.js`) — hex le plus proche, `null` hors plateau                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Raster statique         | `buildBoardLayer` (`render/board.js`) — terrain + glyphes, 1× par partie                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Couche dynamique        | `draw` (`render/stage.js`) — surbrillance secteur actif, aides, unités                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## Pièges connus

- `sectorsOf` **code en dur** les colonnes 4/8 (paires) et 3/7 (impaires) : changer `W`
  dans `config.js` casserait les secteurs silencieusement. `sectorLinesX` (`render/gfx.js`)
  code aussi les colonnes 4 et 8. À réviser ensemble si le plateau change de taille.
- Un hex à distance 2 dont l'**unique** chemin passe par un hex occupé est inatteignable
  — comportement voulu, documenté dans `test/movement.test.js`.
- Restrictions de tir après mouvement : elles ne sont PAS dans `reachable` mais dans
  `targetsFor` (`src/combat.js`) — voir le skill `combat`.

## Ajouter un type de terrain

1. `src/config.js` → entrée dans `TERRAIN` : `{ label, dice: { def, defArmor?, defArt? }, stops, blocksSight?, elevated?, enterAdjacentOnly?, exitAdjacentOnly?, noFightOnEnter?, impassable?, noFight?, noRetreatInto? }`.
2. `src/scenario.js` → placer les hexes : `put('<type>', [[c, r], …])`.
3. `render/gfx.js` → couleur dans `COL['<type>']`.
4. `render/board.js` → glyphe éventuel (modèles : `foret` ▲▲, `colline` arc, `village` rectangle).
5. `styles.css` → règle `#tip .thead.<type>` (bandeau de l'infobulle).
6. Tests : `test/scenario.test.js` (placement) + `test/combat.test.js` si le terrain
   modifie les dés ou coupe la ligne de mire (`blocksSight`) + `test/movement.test.js` s'il a
   `stops: true` ou des restrictions d'entrée/sortie (bocage).

## Ajouter un type d'obstacle

1. `src/config.js` → entrée dans `OBSTACLES` : `{ label, dice: { def, defArmor?, defArt? }, blocksSight?, infantryOnly?, fixesArtillery?, ignoreFirstFlag?, removedOnExit?, makesPassable? }`.
2. `src/scenario.js` → le poser : `obstacles[key(c, r)] = '<type>'`.
3. `render/board.js` → son dessin dans le raster (modèle : bunker, rectangle épais + meurtrière).
4. `render/html.js` → le bloc d'infobulle est généré depuis les drapeaux connus ; ajouter une ligne si le nouvel obstacle introduit un drapeau inédit.
5. Nouvelle capacité d'obstacle = nouvelle propriété de config appliquée dans `src/movement.js` (accès) ou `src/combat.js` (défense, drapeaux, ligne de mire) + test.
6. Tests : `test/scenario.test.js` (placement) + `test/combat.test.js` / `test/movement.test.js` selon les règles.

## Modifier une règle de mouvement

1. `src/movement.js` (`reachable`) pour le coût/blocage ; `src/config.js` pour les
   capacités (`move`, `moveNoFire`).
2. `test/movement.test.js` (macro : état fabriqué avec `flatState`).
3. Vérifier les trois consommateurs : `app.js` `selectUnit`, `game.js` `moveUnit`,
   `ai.js` `aiPlanUnit` (qui duplique les seuils dans `canFire`).
4. Si la règle est visible du joueur : mettre à jour `MOVE_LBL` (`render/html.js`).
